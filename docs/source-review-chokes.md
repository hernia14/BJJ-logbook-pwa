## 2. 既存カードへの所見

### 2-1. 裸絞めに「手首で絞める型」と「前腕で絞める型」の区別がない

- **対象**: `rear-naked-choke.yaml`（7枚）
- **所見**: 本書 3章は「手首で絞める裸絞め」（p.75）と「前腕で絞める裸絞め」（p.76）を
  別項目として扱っている。前者は相手の顎が入らないため柔道でよく使われる、と説明されている。
  現行カードはこの区別を持たず、1つの技として書いている。
- **提案**: 区別を設けるか、少なくとも定義カードで型が複数あることに触れる。
  ただし**どちらを主として教えるかは指導方針の問題**なので、判断を仰ぎたい。

### 2-2. 裸絞めの「腕の位置」の記述が本書と食い違う可能性

- **対象**: `rear-naked-choke-req-01`
- **現行の記述**: 「首に回した腕の肘が相手の顎の真下、首の中心線に来ていること」
- **本書の記述**: 4条件のPoint 4として「顎の近くに力を入れても絞まりづらい。
  首の付け根を狙う」。また手首で絞める型では「両拳を相手の左右の首の付け根に当てる」（p.75）。
- **所見**: 「肘を顎の真下に」は英語圏の一般的な指導表現で、本書の「首の付け根を狙う」と
  必ずしも矛盾しないが、**強調点が明確に異なる**。現行カードは私のWeb調査由来であり、
  一次資料のほうが精度が高いと考えられる。
- **提案**: 本書に寄せて書き換える。ただし**あなたの指導表現を優先したい**ので、
  どう表現するか指示してほしい。

### 2-3. 「なぜ効かないか」の説明が浅い

- **対象**: 絞め技カード全般の `principle` 軸
- **所見**: 現行カードは「頸動脈を圧迫する」で説明を止めているものが多い。
  本書は「圧力が後頭部の隙間から逃げる」「輪が閉じていないと血流は止まらない」と、
  **効かない理由**まで踏み込んでいる。
- **提案**: 新規作成した `choke-principles.yaml` を各絞めカードから
  `tags.concepts` で参照させ、原理は概念カード側に集約する。
  個別カードを厚くするより重複が減る。

### 2-4. 頭の位置に関する禁忌の記述がない

- **対象**: `rear-naked-choke.yaml`
- **所見**: 本書は「頭を上げていると極まりにくい」をNGムーブとして挙げ、
  理由を「相手の後頭部を止めるものがないので、首を絞める輪が完成しないから」と説明している。
  現行カードにこの観点はない。
- **提案**: `common_mistake` / `consequence` のペアとして追加する。
