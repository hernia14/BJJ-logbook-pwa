## 2. 既存カードへの所見（2026-08-11 すべて反映済み）

### 2-1. 裸絞めに「手首で絞める型」と「前腕で絞める型」の区別がない

- **対象**: `rear-naked-choke.yaml`（7枚）
- **所見**: 本書 3章は「手首で絞める裸絞め」（p.75）と「前腕で絞める裸絞め」（p.76）を
  別項目として扱っている。前者は相手の顎が入らないため柔道でよく使われる、と説明されている。
  現行カードはこの区別を持たず、1つの技として書いている。
- **判断**: 型ごとに分ける（本人決定）
- **対応済み**: `rear-naked-choke.yaml` を削除し、`rear-naked-choke-wrist.yaml`（9枚）と
  `rear-naked-choke-forearm.yaml`（13枚）へ分割した。使い分けの理由（柔道で手首型が
  使われ、前腕型が使われにくい理由）も定義カードに含めた。

### 2-2. 裸絞めの「腕の位置」の記述が本書と食い違う可能性

- **対象**: `rear-naked-choke-req-01`
- **現行の記述**: 「首に回した腕の肘が相手の顎の真下、首の中心線に来ていること」
- **本書の記述**: 4条件のPoint 4として「顎の近くに力を入れても絞まりづらい。
  首の付け根を狙う」。また手首で絞める型では「両拳を相手の左右の首の付け根に当てる」（p.75）。
- **所見**: 「肘を顎の真下に」は英語圏の一般的な指導表現で、本書の「首の付け根を狙う」と
  必ずしも矛盾しないが、**強調点が明確に異なる**。現行カードは私のWeb調査由来であり、
  一次資料のほうが精度が高いと考えられる。
- **判断**: 本書に寄せる（本人決定）
- **対応済み**: 「顎の真下」という記述を廃し、「首の付け根を狙う」に統一した。

### 2-3. 「なぜ効かないか」の説明が浅い

- **対象**: 絞め技カード全般の `principle` 軸
- **所見**: 現行カードは「頸動脈を圧迫する」で説明を止めているものが多い。
  本書は「圧力が後頭部の隙間から逃げる」「輪が閉じていないと血流は止まらない」と、
  **効かない理由**まで踏み込んでいる。
- **判断**: 集約する（本人決定）
- **対応済み**: 絞め技14ファイルすべての `tags.concepts` に `choke-principles` を追加した。

### 2-4. 頭の位置に関する禁忌の記述がない

- **対象**: `rear-naked-choke.yaml`
- **所見**: 本書は「頭を上げていると極まりにくい」をNGムーブとして挙げ、
  理由を「相手の後頭部を止めるものがないので、首を絞める輪が完成しないから」と説明している。
  現行カードにこの観点はない。
- **判断**: 追加する（本人決定）
- **対応済み**: 手首型に「頭を上げていると輪が完成しない」、前腕型に「手のひらで
  後頭部を押すと輪が不完全」「肘が首より前だと腕を制される」を因果ペアで追加した。

## 2-5.【重要】絞め防御の「顎を引く」が無条件に書かれていた

- **対象**: 8ファイル（`back-escape` `guillotine-defense` `back-control`
  `bow-and-arrow-choke` `cross-collar-choke` `ezekiel-choke`
  `rear-naked-choke-wrist` `rear-naked-choke-forearm`）
- **現行の記述**: 防御として「顎を引いて首元の空間を消す」と無条件に書いていた
- **本書の記述**（下巻 p.82 技の豆知識「絞められたとき、アゴは引かず首筋に力を入れよ」）:
  絞めが入る前に顎を引くのは有効だが、**首に相手の腕や道衣が密着した後に顎を引くのは
  無意味どころか有害**。のどぼとけ周辺が凹み、相手の力がそこに集中してしまうため。
  密着後は首筋に力を入れて首をまっすぐ固くする。そうすると絞める手や襟が顎方向へ滑り、
  「首の中心軸に垂直に力をかける」ことがしづらくなり、筋肉が頸動脈を守る。
  また顎を引くと息が吸えない。
- **所見**: 一般に「顎を引け」と広く教えられており、私のWeb調査由来のカードも
  それをそのまま書いていた。**段階による使い分けが抜けていた。**
- **対応済み**: 該当8ファイルの記述に「絞めが入る前の段階で」という条件を補い、
  `concepts/choke-defense-timing.yaml`（7枚）を新設して参照させた。
- **要確認**: 広く教えられている内容と食い違うため、**あなたの指導表現と一致するか
  レビュー時に確認してほしい。** 一致しない場合はあなたの表現を優先する。
