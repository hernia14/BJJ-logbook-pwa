# 一次資料の台帳

カード作成に使った資料の版・取得日・所在を記録する。
**資料そのもの（PDF等）はGit管理しない**（`.gitignore` 参照）。ここに記録するのはメタ情報だけ。

この台帳の役割は2つ。

1. カードの `sources` から資料を辿れるようにする
2. 資料が改訂されたとき、影響を受けるカードを機械的に特定する（`docs/requirements.md` §E）

## 条項の台帳（ルールカード用）

IBJJFルールが v7.0 へ改訂された際、影響を受けるカードを特定するために使う
（`docs/requirements.md` §E）。ルールカードを作り始めたら埋める。

| clause_id | v6.0 のセクション | 内容の要約 | 紐づくカードid |
|---|---|---|---|
| （例）`points-mount` | （記入） | （記入） | （記入） |

改訂時の手順:

1. 新版の該当セクションを新旧で突き合わせる
2. セクション番号または内容が変わった `clause_id` を洗い出す
3. 紐づくカードを再レビュー対象としてフラグを立てる
4. 旧版のカードは上書きせず、新版として追加する（過去の版を参照できるようにするため）

PDFの自動差分解析は行わない。誤検知・見逃しのリスクが高く、
ルールの誤りは競技上の判断を誤らせるため、人間のレビューを必ず介在させる。
