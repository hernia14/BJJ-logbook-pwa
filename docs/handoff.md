## 5. PDFの読み方（重要）

一次資料はスキャン画像PDFで、テキスト抽出できない。100MB超のため直接読み込みもできない。
ページを画像として取り出してから読む。

**PDFページ番号 → 書籍ページ番号の対応**（下巻）

    PDFページ N は書籍ページ (2N-4) と (2N-3) の見開き
    逆算: 書籍ページ B → PDFページ = (B+4)/2 を切り捨て

例: 書籍 p.46 → PDF 25、書籍 p.53 → PDF 28

**取り出しコマンド**（スクラッチ領域へ出力する。リポジトリには入れない）

```bash
python -X utf8 -c "
from pypdf import PdfReader
from PIL import Image
from io import BytesIO
r=PdfReader('docs/sources/寝技の学校 下巻.pdf')
n=25  # PDFページ番号
img=Image.open(BytesIO(list(r.pages[n-1].images)[0].data)).convert('RGB')
img=img.resize((1900,int(img.height*1900/img.width)), Image.LANCZOS)
img.save('OUT.jpg','JPEG',quality=85)
"
```

出力したJPEGを Read ツールで読む。1見開きあたり約400KB。
**トークン節約のため、1回に読むのは1〜2見開きまで。読んだ直後にカード化する。**
